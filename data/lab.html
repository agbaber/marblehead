About the database. Built from the curated CSVs in data/. Every table has a row in _meta with its primary-source citation — try SELECT * FROM _meta;. Open the downloaded file in DB Browser for SQLite, the sqlite3 CLI, Python's sqlite3, R's DBI, or any tool that reads SQLite. Rebuild locally with python3 scripts/build_sqlite_db.py.
