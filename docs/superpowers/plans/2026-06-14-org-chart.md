# Org Chart Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `/org-chart.html` ("Who runs Marblehead?") — a standalone page with a side-by-side town/schools org chart (two-tier expand), an elected-boards panel, and a voter-role section.

**Architecture:** Plain Jekyll page. Data lives in `_data/org_chart.yml`; markup is Liquid loops over that data so the page itself stays short. No SVG, no JS dependency — `<details>` for expand/collapse and CSS borders for connectors. New scoped block in `assets/site.css` for `.org-chart`, `.org-card`, `.board-card`. Citations via the existing `<sup class="cite">` pattern; `assets/citations.js` auto-injects the Sources `<h2>` at render.

**Tech Stack:** Jekyll 3.10, Liquid, HTML, scoped CSS, Playwright for smoke + proof screenshots. No new JS.

**Spec:** `docs/superpowers/specs/2026-06-14-org-chart-design.md`

---

## File Structure

- **Create** `org-chart.html` — the page itself; Liquid loops over `site.data.org_chart`.
- **Create** `_data/org_chart.yml` — canonical source for the chart, boards, key stats. Single file so structure stays in one place and changes are diff-reviewable.
- **Modify** `assets/site.css` — append a new scoped `/* === Org chart === */` block.
- **Create** `proof/<branch>.png` and `proof/<branch>-full.png` — Playwright screenshots committed as proof of work.
