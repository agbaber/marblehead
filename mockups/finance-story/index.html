Three ways to tell the same story.

Each mockup is a working scrollytelling page: a pinned visualization with seven scroll-stops, the visualization morphing as the reader scrolls. Same source material, three different arcs and design treatments. Pick the one closest to what you want; the design can be refined from there.

Mockup A

The Dollar Journey

Arc: $1 → 3 shapes → per-FTE stack → people grid → org → boards → trajectory

Design: editorial / magazine. Navy + buoy palette, Libre Franklin headlines, generous whitespace. The closest to the existing town-history feature.

 Mockup B

The Workforce

Arc: 1,020 people → categories → per-FTE cost → 80% of budget → org → boards above → trajectory

Design: humanizing / illustrative. Sage + teal palette, warmer surface, larger body text, sans-serif headlines. Leads with people, walks back to numbers.

 Mockup C

Twenty Years

Arc: trajectory → 3 forces → stack → composition → today → org → roster

Design: dashboard / dataroom. Plum + buoy palette, denser layout, smaller panels, more numbers visible. Closest to a financial briefing.
